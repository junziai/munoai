1. **导出 MIDI**（现有 export_midi_tracks_to_folder 逻辑不变）。
2. **导出乐谱**：
   - 依赖 MuseScore Studio 4（已在资源目录，含下载）。

验收：菜单结构与参考项目一致（MIDI/乐谱/转录HQ/转录兼容/分轨HQ/分轨兼容/立体声），三语言文案齐全。

### 3. MIDI 音符一键「智能清理」（新手向 AI 修复）
结果工作台编辑工具栏新增**智能清理**按钮（量化旁，三语 i18n），一键修复四类转谱常见错误（确定性规则，可一键撤销，带统计报告）：
1. **超短杂音音符**（< 40ms）删除 —— 模型幻觉毛刺。
2. **同音重叠/贴叠合并**（重叠或间隙 < 30ms 同音双触发）—— 合并时值、取较大力度。
3. **力度离群平滑** —— 低于轨道中位数 45%（且 < 24）的"幽灵弱音"提升至中位数（保留节奏不删音）。
4. **音域外幻觉音符删除** —— 旋律轨 21–108 / 鼓轨（channel 9）27–87 之外的音直接移除。
- 报告示例：「清理完成：删除超短音符 12 个 · 合并重叠 5 处 · 平滑力度 3 个 · 移除音域外 2 个」；无改动时提示"已经非常干净"。
- 全部记录为**单步撤销**（applyEdit），编辑即触发试听音频重渲染（scheduleResynthesis）。

## 六、深度分析与建议（扒带效率 / 编辑效率 / UI 新手友好）

### 1. 软件一句话定位
**"听歌 → 出谱"的全能工作站**：任意歌曲拖进来，自动分轨 → 多模型转 MIDI → 钢琴卷帘精修 → 歌词提取改词 → 一键换音源试听导出（MIDI / 乐谱 / 分轨 WAV / 立体声混音），全流程本地 GPU，零外网依赖（资源按需下载）。

### 2. 扒带最快最干净的分场景打法（推荐工作流）
| 场景 | 推荐模式/模型 | 干净度理由 |
|---|---|---|
| 纯钢琴曲 | PIANO_TRANSKUN（TransKun 2.0） | 钢琴专用 SOTA，含踏板，误差最小 |
| 流行歌全曲伴奏 | SMART（YourMT3+ MoE） | 多乐器 MoE，全轨一把出 |
| 只要主旋律 | VOCAL_SPLIT → 人声轨单独转 | 先分人声再转，其余乐器干扰归零 |
| 密集编曲（金属/交响） | SIX_STEM → 逐轨转 | 六声部分离后每轨信噪比最高 |
| 快速草稿试音 | PIANO_ARIA（轻量） | 秒级出稿，后期再精修 |
**三步精修法**：智能清理（去毛刺）→ 量化（1/16 或 1/32 对拍）→ 耳听微调（A/B 立体声对比原声与 MIDI，mix 滑杆实时对听）。扒带效率的最大杠杆是 **A/B 立体声 + mix 75** —— 左耳原声右耳 MIDI，错音漏音无所遁形。

### 3. 开源修复方案调研结论（为何选确定性规则而非大模型）
- 调研对象：all-in-one-ai-midi-pipeline（onset/offset 阈值清理）、MT3-Infer（-16 LUFS 归一化预处理）、ADTOF（鼓谱专用）、miditoolkit 常规清理（`trim_overlapping_notes`/`remove_noise` 套件）。
- 结论：**转谱错误的 90% 是四类机械伪影**（超短音/同音双触发/幽灵弱音/音域外幻觉），确定性规则即可修复且零误伤；引入大模型二次修正反而带来不可解释、需联网、推理慢三重代价。本工程智能清理 = miditoolkit 套件的"新手一键版"。
- 未来若要更强：可加**调性约束修复**（Krumhansl-Schmuckler 调性检测 → 离调且短且弱的音符校正/删除），已预留智能清理的扩展位。

### 4. AI 原创音乐的快速扒带路径（"采样再创作"）
1. 扒骨架：SIX_STEM 分离 → 只留鼓/贝斯/和声轨 → 导出 MIDI。
2. 换皮：任意 GM 音源（如 Arachno 复古风）整轨替换试听 —— 30 秒把流行编曲变 8-bit 风。
3. 改词：歌词面板改写 → 写回 MIDI lyric → SoVITS/合成器直接唱新词。
4. 变速变调：工程 BPM/移调（方向键 + Shift 八度）做整体改编。
   （即"扒带 → 替换 → 改写"三段式，全程不离开本软件。）

### 5. UI 新手友好评估与改进方向
现状优点：紫色主题统一、资源管理三分区（必备/扩展/模型）+ 新手提示 💡 + 星级评分、结果工作台所有操作有 tooltip。
